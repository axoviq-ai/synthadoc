# Defect Tracker

Running log of quality defects and non-conformances. Track by: defect code, part number, quantity, detection stage (incoming inspection, in-process, final inspection, field return), defect description, root cause category, and disposition (use-as-is, rework, scrap, return to supplier). Use this data to generate a Pareto analysis of top defect codes monthly.
