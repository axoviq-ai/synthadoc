# Properties

Property register for all investments in the portfolio. Each property page records: address, property type (multifamily, office, industrial, retail, mixed-use), square footage or unit count, year built, acquisition date, acquisition price, current valuation, key tenants, occupancy rate, current NOI, and investment status (prospective, active, exited).
