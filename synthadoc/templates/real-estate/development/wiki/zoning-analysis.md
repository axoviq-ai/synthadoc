# Zoning Analysis

Zoning and entitlement analysis for all development projects.

Each zoning analysis record captures:

- **Site identity** — parcel APN, address, lot area (sf / acres), existing improvements
- **Current zoning** — zoning district designation, general plan land use designation, overlay zones (flood, fire, coastal, historic, affordable housing)
- **Allowed uses** — permitted-by-right uses, conditionally permitted uses, prohibited uses in the district
- **Development standards** — maximum FAR, maximum height, minimum setbacks (front / rear / side), minimum lot coverage, minimum parking ratio, open space requirements
- **Entitlement type required** — by-right / administrative approval / conditional use permit / variance / rezoning / general plan amendment; applicable process timeline
- **Density and incentives** — base density, state density bonus eligibility, affordable housing units required, inclusionary percentage
- **Environmental review** — CEQA / NEPA applicability, exemption category, negative declaration, or EIR status; key environmental constraints (biological, cultural, hazmat)
- **Legal conformance** — any legal non-conforming status, grandfather conditions, notice of determination
