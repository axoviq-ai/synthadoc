# Change Orders

Change order log for all active development projects.

Each change order record captures:

- **Change order identity** — CO number, project name, GC or subcontractor, CO date, description of scope change
- **Cost impact** — CO amount (positive for additions, negative for deductions), updated contract value, cumulative CO total, CO total as % of original contract
- **Schedule impact** — days added or removed, revised substantial completion date
- **Approval status** — draft / submitted / under review / approved / rejected; approval authority (owner, owner's rep, architect)
- **Root cause** — design error / owner-directed change / unforeseen site condition / value engineering / regulatory requirement
- **Backup documentation** — linked proposal, time-and-material tickets, subcontractor quotes, RFI that triggered the change
- **Budget line item** — which budget line absorbs the change; whether drawn from contingency
