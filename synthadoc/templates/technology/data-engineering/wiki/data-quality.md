# Data Quality

Data quality rules and monitoring for all managed datasets. Each rule entry records: dataset, column(s), rule type (not-null, range, uniqueness, referential integrity, freshness), threshold, severity (warning/error/critical), owner, and current pass rate. Documents the alerting path when rules breach and the remediation SLA.
