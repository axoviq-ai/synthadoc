# Trademark Record — Intake Form

> **How to use this form**
>
> This template follows the **USPTO Trademark Electronic Application System (TEAS) + Nice Classification (11th Ed.)** -- the standard structure for documenting trademark records and prosecution history.
> If you already have TM records in another format, skip this form and ingest your document directly.
>
> Reference: [USPTO Trademarks](https://www.uspto.gov/trademarks)
>
> 1. Copy this file and rename it (e.g. `US6543210-brand-name.md`)
> 2. Fill in all sections
> 3. Run: `synthadoc ingest raw_sources/trademarks/<serial-number>-<mark-name>.md -w <wiki>`
>
