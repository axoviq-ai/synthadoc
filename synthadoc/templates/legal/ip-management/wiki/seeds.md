# Getting Started — IP Management

## Recommended first ingests

**Google Patents (your company's portfolio)**
```
synthadoc ingest "https://patents.google.com/?assignee=<your+company+name>" -w <wiki>
```

**USPTO Patent Full-Text Database**
```
synthadoc ingest "https://patft.uspto.gov/netahtml/PTO/search-adv.htm" -w <wiki>
```
