# Learning Assessment — Template

> **How to use this form**
>
> This template follows the **Bloom's Taxonomy of Educational Objectives (Anderson & Krathwohl, 2001) + Kirkpatrick Level 2** --
> the standard framework for designing assessments that verify learning and measure knowledge gain.
> If you already have an assessment in another format, skip this form and ingest your document directly.
>
> Reference: [Bloom's Taxonomy](https://www.bloomstaxonomy.net/)
>
> 1. Copy this file and rename it (e.g. `hipaa-privacy-assessment-v2.md`)
> 2. Fill in all sections
> 3. Run: `synthadoc ingest raw_sources/assessments/<filename>.md -w <wiki>`
