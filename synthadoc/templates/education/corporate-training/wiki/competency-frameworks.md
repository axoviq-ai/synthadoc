# Competency Frameworks

Behavioral and technical competency frameworks used for role definition, hiring, performance management, and development. Each framework record captures:

- **Framework identity** — framework name, applicable role family or level (individual contributor, manager, executive), version, effective date
- **Competency domains** — the broad categories the framework covers (e.g., Technical, Communication, Leadership, Customer Focus, Collaboration)
- **Competency definitions** — for each competency: name, behavioral definition, and observable indicators at each proficiency level (typically 1–4 or Developing / Proficient / Advanced / Expert)
- **Proficiency level descriptions** — what each level looks like in practice; the behavioral anchors used for calibration
- **Assessment method** — how the competency is assessed: self-assessment, manager rating, 360, skills test, work sample
- **Development resources** — recommended training, books, stretch assignments, or mentoring to develop each competency (link to [[training-catalog]])
- **Role mapping** — which competencies are required at each level for each role family (link to job framework)
