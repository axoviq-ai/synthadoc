# Technology Tools

EdTech tools and platforms used in instruction and course delivery. Each tool record captures:

- **Tool identity** — tool name, vendor, version or plan tier, primary use category (LMS, authoring, video, collaboration, assessment, simulation, proctoring, analytics)
- **Purpose** — what instructional function this tool serves; which modules or course types use it (link to [[modules]])
- **Features used** — the specific features in active use; which features are available but not being used
- **Access and licensing** — who has access (students, instructors, administrators); cost model (per seat / per course / institutional license); contract renewal date
- **Accessibility compliance** — VPAT availability; known accessibility gaps; workarounds in use
- **Integration** — which other tools this integrates with (LMS, SSO, gradebook, analytics platform)
- **Support and training** — where instructors get help; known pain points; training resources available

Cross-link to [[modules]] for modules that rely on each tool, [[facilitation-guides]] for tool-specific delivery instructions, and [[learning-materials]] for content created with each tool.
