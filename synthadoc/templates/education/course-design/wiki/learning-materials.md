# Learning Materials

Repository of participant materials, readings, and multimedia used in instruction. Each material record captures:

- **Material identity** — title, author or creator, type (textbook chapter, article, video, infographic, simulation, dataset, template, case study)
- **Course or module use** — which modules this material is used in (link to [[modules]]); whether it is required or optional
- **Source and access** — URL, file path, or library reference; license or access restriction (open access / licensed / proprietary)
- **Purpose** — what learning objective this material supports; how learners should engage with it (read before class, reference during activity, work through exercises)
- **Estimated time** — reading time, video length, or estimated completion time
- **Accessibility** — whether captions, transcripts, alt text, or alternative formats are available
- **Review date** — when the material was last checked for accuracy and currency; next review due

Cross-link to [[modules]] for the modules using each material, [[learner-outcomes]] for the objective each material supports, and [[facilitation-guides]] for how instructors use each material in delivery.
