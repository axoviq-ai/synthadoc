# Modules

Module library for this course or curriculum. Each module page records: module title, estimated duration, level (introductory/intermediate/advanced), learning objectives (Bloom's level for each), prerequisite modules, content outline, delivery format (synchronous/asynchronous/blended), required materials, and assessment methods. Cross-link to [[learning-materials]] and [[assessments]] used in each module.
