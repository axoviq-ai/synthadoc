# Course Notes — Template

> **How to use this form**
>
> This template follows the **Cornell Note-Taking System (Walter Pauk, Cornell University) + Zettelkasten atomic notes** --
> the structured method for capturing, reviewing, and connecting ideas from formal courses.
> If you already have course notes in another format, skip this form and ingest your document directly.
>
> Reference: [Cornell Note-Taking System](https://lsc.cornell.edu/how-to-study/taking-notes/cornell-note-taking-system/)
>
> 1. Copy this file and rename it (e.g. `fast-ai-practical-deep-learning-2026.md`)
> 2. Fill in all sections
> 3. Run: `synthadoc ingest raw_sources/courses/<course-name>.md -w <wiki>`
