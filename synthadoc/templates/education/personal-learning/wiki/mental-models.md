# Mental Models

Powerful frameworks for thinking and decision-making. Each model page records: model name, originating domain (economics, psychology, physics, etc.), core insight in one sentence, how to apply it, common misapplications to avoid, and cross-links to [[concepts]] and [[books]] where the model appears. Organize by the cognitive function each model serves (decision-making, problem-solving, systems thinking, etc.).
