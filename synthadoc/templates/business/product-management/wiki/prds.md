# Product Requirements Documents

PRD library indexed by feature area. Each PRD page records: feature name, problem statement, target user(s), user stories with acceptance criteria, out-of-scope items, success metrics with baseline and target values, technical dependencies, design assets link, and status (draft/in-review/approved/shipped). Cross-link to the [[customer-research]] that motivated the feature and the [[product-metrics]] it is intended to move.
