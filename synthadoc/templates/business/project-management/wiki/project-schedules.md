# Project Schedules

Detailed work breakdown and schedule for all active projects.

Each project schedule captures:

- **Schedule identity** -- project (link to [[projects]]), baseline date, current revision, scheduler
- **Work breakdown structure (WBS)** -- major phases, deliverable groupings, work packages; numbering convention (1.0 Initiation / 2.0 Planning / 3.0 Execution / 4.0 Closeout)
- **Key activities** -- activity name, WBS code, duration, start date, end date, predecessors, responsible party
- **Critical path** -- which activities are on the critical path; total float; near-critical activities (float <= 5 days)
- **Milestones** -- milestone name, baseline date, forecast date, actual date, delta
- **Schedule health** -- schedule performance index (SPI), days ahead/behind baseline, recovery plan if behind
- **Resource loading** -- peak resource demand weeks; over-allocated resources and leveling plan

Cross-link to [[projects]], [[project-charters]], [[raid-log]], and [[status-reports]].
