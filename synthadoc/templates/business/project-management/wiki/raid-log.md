# RAID Log

Risks, Assumptions, Issues, and Dependencies tracker for all active projects.

Each RAID entry captures:

- **Entry identity** -- ID (e.g. R-001, A-002, I-003, D-004), project (link to [[projects]]), category (Risk / Assumption / Issue / Dependency), date raised, raised by
- **Description** -- what the risk, assumption, issue, or dependency is; current state
- **Risk attributes** (Risks): probability (H/M/L), impact (H/M/L), risk score, risk type (schedule / budget / scope / quality / resource / external), response type (Avoid / Mitigate / Transfer / Accept)
- **Assumption attributes** (Assumptions): consequence if wrong, validation method and deadline
- **Issue attributes** (Issues): impact (H/M/L), urgency (H/M/L), resolution type (Resolve / Escalate / Accept)
- **Dependency attributes** (Dependencies): dependent-on team or system, what is needed, by when, consequence if late
- **Response / mitigation plan** -- specific actions, owner, due date
- **Status** -- Open / Monitoring / Escalated / Closed; resolution description for closed items

Cross-link to [[projects]], [[project-charters]], [[stakeholder-map]], and [[status-reports]].
