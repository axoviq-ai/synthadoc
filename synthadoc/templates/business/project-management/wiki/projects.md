# Projects

Active and recently completed project registry. Each project entry records: project name, sponsor, project manager, start date, target end date, current status (green/yellow/red), budget (approved and spent-to-date), top risk, and next key milestone. Cross-link to the full [[project-charters]], [[project-schedules]], and [[raid-log]] for each project.
