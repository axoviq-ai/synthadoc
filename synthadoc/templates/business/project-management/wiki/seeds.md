# Getting Started — Project Management

## Recommended first ingests

**Your existing project charter or kickoff documents**
```
synthadoc ingest docs/projects/ --batch -w <wiki>
```

**Recent status reports**
```
synthadoc ingest docs/status-reports/ --batch -w <wiki>
```

## Recommended web searches

- `project charter template PMI PMBOK scope objectives` — charter format
- `RAID log template risks assumptions issues dependencies` — RAID management
- `stakeholder analysis power interest grid template` — stakeholder mapping
- `project status report template weekly executive summary` — status reporting
- `agile retrospective formats start stop continue` — retrospective process

## First steps checklist

- [ ] Create a project charter for your current highest-priority project
- [ ] Populate the RAID log with the top 5 risks and open issues
- [ ] Build a stakeholder map for the project
- [ ] Ingest your most recent status report
- [ ] Run scaffold to build the index
