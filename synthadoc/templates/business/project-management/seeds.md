## First steps checklist

- [ ] **Create a project charter** -- copy `raw_sources/charters/template-project-charter.md`,
  rename it (e.g. `erp-migration-q4-2026.md`), fill in the project identity, objectives,
  scope, deliverables, budget, and milestones, get sponsor sign-off, then:
  ```
  synthadoc ingest raw_sources/charters/<project-name>.md -w <wiki>
  ```
  Populates [[project-charters]] and [[projects]].

- [ ] **Document your kickoff meeting** -- copy `raw_sources/kickoff/template-project-kickoff.md`,
  rename it (e.g. `erp-migration-kickoff-2026-10-01.md`), fill in attendees, agenda outcomes,
  decisions made, and action items, then:
  ```
  synthadoc ingest raw_sources/kickoff/<project-name>-kickoff.md -w <wiki>
  ```
  Populates [[projects]] with scope confirmation, team assignments, and open questions.

- [ ] **Build a RAID log** -- place your risks, assumptions, issues, and dependencies in
  `raw_sources/` (Excel, CSV, or Markdown), then ingest:
  ```
  synthadoc ingest raw_sources/<project>-raid.xlsx -w <wiki>
  ```
  Populates [[raid-log]]. Use the Smartsheet template from "Recommended first ingests" as a starting point.

- [ ] **Add your stakeholder map** -- ingest your stakeholder analysis when it is ready:
  ```
  synthadoc ingest raw_sources/<project>-stakeholders.md -w <wiki>
  ```
  Populates [[stakeholder-map]].

- [ ] **Run scaffold to build the index**
  ```
  synthadoc scaffold -w <wiki>
  ```
