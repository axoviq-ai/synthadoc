# Project Charter: [Project Name]

> **How to use this form**
>
> This template follows the **PMI/PMBOK 6th edition** project charter structure -- the most widely
> adopted global standard for project management. If you already have a charter in another format
> (Word, Notion, PDF), skip this form and ingest your existing document directly.
>
> Reference: [PMBOK Guide, 6th Ed., Section 4.1.3.1](https://www.pmi.org/pmbok-guide-standards)
>
> 1. Copy this file and rename it (e.g. `erp-migration-q4-2026.md`)
> 2. Fill in at project kickoff; get sponsor sign-off before execution begins
> 3. Run: `synthadoc ingest raw_sources/charters/erp-migration-q4-2026.md -w <wiki>`
>
> Re-ingest when scope, budget, or timeline changes materially.
