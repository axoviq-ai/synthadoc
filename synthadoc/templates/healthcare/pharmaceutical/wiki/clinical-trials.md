# Clinical Trials

Active and completed clinical trials. Each trial page records:

- **Trial identity** — NCT number, sponsor, phase, indication, official title, study ID
- **Primary endpoint** — the primary endpoint and the statistical hypothesis being tested; minimum clinically important difference
- **Enrollment** — target enrollment and actual enrollment; key eligibility criteria summary
- **Status** — Screening / Enrolling / Fully enrolled / Completed / Terminated; primary completion date
- **Key results** — primary endpoint result (HR, ORR, PFS, OS, etc.); p-value; confidence interval; clinical significance
- **Protocol version** — link to [[protocols]] for the protocol under which the trial is run
- **Safety summary** — key adverse events; discontinuation rate; deaths on study
- **Publications and presentations** — citation for primary paper; key ASCO, ESMO, or ASH presentation if applicable

Cross-link to [[protocols]] for the study design, [[compounds]] for the investigational product, [[regulatory-submissions]] for the IND and any NDA/BLA submission referencing this trial, and [[safety]] for expanded adverse event data.
