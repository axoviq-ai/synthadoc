# Protocols

Clinical study protocols and their versions. Each protocol record captures:

- **Protocol identity** — protocol number, study title, compound (link to [[compounds]]), NCT number, protocol version and version date
- **Study design** — phase, type (randomized / single-arm / open-label / blinded), comparator or control arm, number of sites
- **Objectives and endpoints** — primary objective; primary endpoint (statistical hypothesis, estimand); key secondary endpoints
- **Patient population** — eligibility: inclusion and exclusion criteria in summary; target enrollment
- **Dosing** — investigational product dose(s) and schedule; comparator dosing; dose modification rules
- **Assessments** — schedule of assessments table: visit frequency, tests, imaging, biomarker collections
- **Statistical plan summary** — sample size rationale, primary analysis method, key interim analysis points
- **Safety monitoring** — Data Safety Monitoring Board (DSMB) composition; stopping rules; AE reporting timelines
- **Amendment history** — protocol versions with summary of material changes and rationale for each amendment

Cross-link to [[clinical-trials]] for the trial running under this protocol, [[compounds]] for the investigational product, and [[regulatory-submissions]] for IND amendments that include the protocol.
