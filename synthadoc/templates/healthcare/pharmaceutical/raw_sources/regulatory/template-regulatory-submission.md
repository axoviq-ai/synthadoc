# Regulatory Submission — Template

> **How to use this form**
>
> This template follows the **ICH M4 Common Technical Document (CTD) + FDA/EMA eCTD format** -- the internationally harmonised structure for organising and submitting pharmaceutical dossiers to regulatory authorities. If you already have a CTD index or submission overview in another format, skip this form and ingest your document directly.
>
> Reference: [ICH M4 Common Technical Document](https://www.ich.org/page/m4)
>
> 1. Copy this file and rename it (e.g. `AXV-101-NDA-2026.md`)
> 2. Fill in all sections
> 3. Run: `synthadoc ingest raw_sources/regulatory/<filename>.md -w <wiki>`
>
> **Note:** This template is for documentation purposes — always follow institutional clinical protocols and regulatory requirements for actual patient care or submissions.
