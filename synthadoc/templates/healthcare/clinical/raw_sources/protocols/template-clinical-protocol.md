# Clinical Protocol — Template

> **How to use this form**
>
> This template follows the **AGREE II Clinical Practice Guideline Appraisal + GRADE evidence framework** -- the international standard for developing and appraising evidence-based clinical protocols. If you already have a clinical protocol in another format, skip this form and ingest your document directly.
>
> Reference: [AGREE II](https://www.agreetrust.org/agree-ii/)
>
> 1. Copy this file and rename it (e.g. `sepsis-management-v2.md`)
> 2. Fill in all sections
> 3. Run: `synthadoc ingest raw_sources/protocols/<filename>.md -w <wiki>`
>
> **Note:** This template is for documentation purposes — always follow institutional clinical protocols and regulatory requirements for actual patient care or submissions.
