# Branch Operations

Branch network performance and operational procedures. Populate by ingesting branch operations manuals, performance reports, and audit findings.

Each branch operations record captures:

- **Branch profile** — branch name, address, charter date, branch manager, FTE count, hours of operation
- **Deposit performance** — total deposits, growth rate, product mix (DDA / savings / CD), household count
- **Lending performance** — loan origination volume by product, pipeline, referral rate to centralized underwriting
- **Operational metrics** — transaction count, teller error rate, vault balancing exceptions, ATM uptime
- **Compliance items** — Reg E error resolution tracking, suspicious activity escalations, cash handling procedures
- **Audit findings** — most recent branch audit date, findings, corrective action status
- **Security and fraud** — robbery response protocol, counterfeit currency procedures, check fraud controls

**How to populate:**

1. Ingest your branch operations manual or procedures guide
2. Ingest branch performance reports (monthly or quarterly)
3. Ingest internal audit reports for specific branches
